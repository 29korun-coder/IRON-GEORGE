# IRON GEORGE – instalace

## Co aplikace umí
- Tréninkový plán na 8 týdnů: kliky, cviky na břicho a švihadlo.
- Záznam tréninků, kalendář, statistiky, 100 XP titulů a milníkové medaile.
- Data se ukládají lokálně v prohlížeči; lze je exportovat a importovat.
- Offline režim po prvním načtení.

## Instalace na Android
Aplikace je PWA. Pro instalaci potřebuje být zveřejněna přes HTTPS (např. GitHub Pages).
1. Rozbal ZIP.
2. Nahraj celý obsah složky na HTTPS hosting (např. GitHub Pages).
3. Otevři adresu webu v Chrome na Androidu.
4. V menu Chrome zvol „Nainstalovat aplikaci“ nebo „Přidat na plochu“.

Samotné otevření `index.html` jako lokálního souboru umožní náhled, ale ne plnou instalaci/offline PWA.

## Důležité
- Plán je výchozí orientační plán pro dospělého v průměrné kondici. Uprav počet opakování podle čisté techniky.
- Zkracovačky, zvedání kolen vleže a prkno jsou jediné břišní cviky v této verzi.
- XP se začnou snižovat až po 10 dnech bez aktivity: 1,5 % za každý další den, maximálně 30 % aktuálního skóre. Zaznamenaný trénink decay zastaví.
- Pro jistotu pravidelně exportuj zálohu; data jsou vázána na prohlížeč/zařízení.
